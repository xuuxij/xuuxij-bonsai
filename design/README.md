# The design sources

The landscape and the tonal clouds are generated by code the design reviewer wrote and
the program carries as its own sections. The sources are kept here so they can be
changed and spliced in again:

- `landscape_shapes.py` — the landscape generator at full design light (paint, halftone,
  ink), the design palette and the painting's constants; `python3 landscape_shapes.py
  135 120 1` prints a backdrop. `splice_landscape.py DIR` replaces the program's
  landscape section from it (DIR holds both files) and appends the Backdrop class and
  the display mapping (the three knobs: `LANDSCAPE_L`, `LANDSCAPE_CHROMA`, `CLOUD_L`).
- `cloud_shapes_r6.py` — the tonal cloud set; `splice_clouds.py DIR` splices it in before
  the Cloud class.
- `landscape_design.md`, `sky_design.md`, `tree_prominence.md` — the reviewer's design
  notes for the landscape, the sky and the tree's prominence.
